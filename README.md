# Tehtävälistasovellus

Yksinkertainen tehtävälistasovellus, joka on toteutettu Reactilla.

## Toiminnot
- Tehtävien lisääminen
- Tehtävien poistaminen
- Tehtävien tallentaminen JSON Serverin avulla

## Käynnistys
Käynnistä backend komennolla `npx json-server --watch db.json --port 3001` ja React komennolla `npm run dev`.
